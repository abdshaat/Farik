# Writing in the brand's voice

A business should sound like itself everywhere. Learn how it sounds before you write, then write
so a reader could not tell which of you wrote it.

## 1. Read what already exists

Before you write, read the business's own words: its website, existing posts and emails, and the Product Manager's spec in `docs/catervas/product/`. Do not start from a blank page when there is a voice to
copy. If nothing exists, ask the user with `catervas_ask_human` for two or three examples of writing
they like, and do not invent a voice.

## 2. Write the voice down

Describe it in three adjectives. For each, give one thing the voice does and one thing it never
does.

- Warm: does greet the reader by name; never uses stiff phrases such as "valued customer".
- Plain: does use short words; never uses jargon the customer would have to look up.

Save the description with the marketing documents so every later piece starts from it. The user
can correct it.

## 3. Write for the reader

- Use short sentences and the reader's own words.
- Put one idea in each paragraph.
- Say what the reader gets before you say what the business is proud of.
- Prefer a plain verb to a phrase: "buy" over "take advantage of the opportunity to purchase".

## 4. Never invent

Never make up a testimonial, a statistic, a customer, a quote, an award or a deadline. If a piece
needs one, write a clearly marked gap, such as "(a customer's words go here)", and tell the user
what to supply.

## 5. Read it aloud

Before you hand it over, read it as the customer: would they know what to do next, and would
they trust the person who wrote it?
