Add airtable to Theo

  1. 1How to start it
  2. 2Label its tools
  3. 3Done

Farik has not checked airtable, so you decide what Theo may do with each of its 8 tools. When unsure, leave “Changes things, asks you”.

Only reads
Theo may use it any time. It looks things up and changes nothing.
Changes things, asks you
Theo asks you before each use, and you see exactly what Theo wants to send.
Never
Theo is not given it.

Each tool’s description comes from airtable.

  • list_basesList the bases you can see.
    list_bases
  • list_recordsList the records in a table.
    list_records
  • search_recordsSearch records for some text.
    search_records
  • describe_tableDescribe a table’s fields.
    describe_table
  • create_recordCreate a record in a table.
    create_record
  • update_recordsChange fields on one or more records.
    update_records
  • delete_recordsDelete one or more records.
    delete_records
  • records.exportExport a table as a file.Farik can’t use this tool: its name has characters Farik can’t pass on. Theo is not given it.
